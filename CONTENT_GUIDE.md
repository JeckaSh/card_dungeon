## 2. Игровой цикл и механики

### 2.1. Формирование колоды этажа
1. В начале забега или при переходе на новый этаж вызывается `_rebuildDeck()` в `lib/screens/game_screen.dart`.
2. Из `allEvents` отбираются карты, у которых:
   - `level == _dungeonLevel`;
   - `isAvailableInDungeon(currentDungeon.id)`: подходят для текущего подземелья либо имеют `dungeonId: DungeonId.common`.
3. Карты перемешиваются (`shuffle`).
4. Если у игрока прокачан навык «Гарантированные торговцы» (`PlayerStatsService.guaranteedMerchants > 0`), в первые 19 карт гарантированно подмешиваются торговцы текущего уровня.

### 2.2. Появление босса и многофазные бои
- Каждая 20-я карта забега (`(cardsPassed + 1) % 20 == 0`) является **боссом**.
- Босс выбирается **случайным образом** из пула боссов текущего этажа данного подземелья (`getBossesForDungeonAndLevel(dungeon.id, currentLevel)`). Для каждого уровня (1, 2 и 3) подземелья предусмотрен пул из нескольких уникальных боссов (по 3 босса на каждый уровень), из которых случайно выбирается один при встрече босса на соответствующем этаже.
- У боссов есть поле `bossPhases` — список из 3 фаз (`BossPhase`).
- Каждая фаза содержит своё название, эмодзи, нарративное описание и варианты выбора (влево/вправо).
- При победе в фазе 1 бой переходит к фазе 2, затем к фазе 3. Зафиксированный босс сохраняется на протяжении всех 3 фаз схватки.
- Использование предметов «Пропуск хода» или «Дымовая шашка» во время битвы с боссом **пропускает только текущую фазу**, а не всю схватку целиком.
- Победа в фазе 3:
  - Если есть следующий этаж (`level + 1 <= dungeon.levelsCount`), уровень увеличивается, пересобирается колода следующего этажа.
  - Если этажи закончились — наступает **Победа** (`GameResult.victory`), золото зачисляется на общий баланс, забег фиксируется в Хронике, и обновляется прогресс ежедневных заданий.

### 2.3. Механика свайпа и расчет урона
- **Свайп влево** активирует `leftChoice`, **вправо** — `rightChoice`.
- Если выбор требует монет (`coinsDelta < 0`) или атаки (`attackDelta < 0`), а у игрока их меньше нужного, свайп **блокируется** и карта возвращается на место.
- Порядок применения модификаторов к выбору:
  1. **Проклятие Мидаса**: если активно, полученные монеты обнуляются.
  2. **Зеркало искажения**: если активно, любые отрицательные дельты обращаются в положительные.
  3. **Рунический щит**: если входящий урон по здоровью `< 0`, щит тратит 1 заряд и полностью поглощает урон.
  4. **Шипованная броня**: если получен урон, герой получает `|урон| * 2` золота.
  5. **Магнит жадности**: удваивает полученное золото.
  6. **Статусы (DoT)**: наложение шансовых статусов (яд, кровотечение, слепота, проклятие) и вычитание периодического урона от уже активных статусов.

## 3. Правила баланса карт

Все карточки в `allEvents` и `allBossCards` проверяются автоматическим тестом `test/card_balance_test.dart` и **строго обязаны соблюдать следующие правила**:

1. **Разделение характеристик выборов**:
   - Каждый отдельный выбор (`CardChoice`) влияет строго либо на здоровье (`healthDelta != 0`), либо на атаку (`attackDelta != 0`).
   - Ни один выбор **не должен влиять одновременно на здоровье и атаку** (`healthDelta != 0 && attackDelta != 0` запрещено).
2. **Альтернативность выборов на карте**:
   - Два выбора на одной карте не должны влиять на один и тот же параметр: если левый выбор меняет атаку, то правый выбор обязан менять здоровье (и наоборот). Это исключает софт-локи и тупиковые ситуации.
3. **Экономика монет**:
   - Обычные боевые монстры, ловушки и привалы не должны беспричинно генерировать монеты. Основной источник монет — сундуки (`treasure`), фазы боссов (`boss`) и специфические алтари.

## 4. Как добавить новую карту события

Все карты событий хранятся в `lib/data/events.dart` в списке `allEvents`.

### 4.1. Типы событий (`EventType`):
- `EventType.monster` — монстры и противники;
- `EventType.trap` — ловушки и опасности;
- `EventType.treasure` — сундуки и сокровищницы;
- `EventType.merchant` — торговцы;
- `EventType.rest` — привалы и святилища исцеления;
- `EventType.mystery` — алтари, тайны и магия.

### 4.2. Доступные статусы (`StatusEffectType`):
- `StatusEffectType.poison` — яд (-1 HP каждый ход в течение 3 ходов);
- `StatusEffectType.bleed` — кровотечение (-2 HP каждый ход в течение 3 ходов);
- `StatusEffectType.blindness` — слепота: скрывает числовые дельты исходов на 3 хода;
- `StatusEffectType.midasCurse` — проклятие Мидаса: всё получаемое золото обнуляется на 3 хода.

### 4.3. Пример добавления карты:
```dart
EventCard(
  id: 'catacombs_crypt_well',
  type: EventType.rest,
  title: 'Затхлый колодец склепа',
  description:
      'Среди разрушенных надгробий бьёт чистый подземный родник, свободный от могильного тлена.',
  leftChoice: CardChoice(
    label: 'Напиться ключевой воды',
    healthDelta: 3,                       // Влияет только на здоровье
  ),
  rightChoice: CardChoice(
    label: 'Омыть и заточить клинок',
    attackDelta: 1,                       // Влияет только на атаку
  ),
  level: 1,                               // Этаж (1, 2 или 3)
  dungeonId: DungeonId.catacombs,         // Привязка к подземелью
),
```

- `type: EventType.boss` — обязательно;
- `level` — этаж, в конце которого босс появляется (1, 2 или 3);
- `dungeonId` — идентификатор подземелья;

## 6. Как добавить новое подземелье

### Шаг 1. Добавьте константу в `DungeonId`
В `lib/models/event_card.dart`:
```dart
class DungeonId {
  static const String common = 'common';
  static const String cursedForest = 'cursed_forest';
  static const String catacombs = 'catacombs';
  static const String elderCaves = 'elderCaves'; // <-- Новый ID

  static String getLabel(String id) {
    if (isCommon(id)) return 'Общий';
    if (id == cursedForest) return 'Проклятый лес';
    if (id == catacombs) return 'Заброшенные катакомбы';
    if (id == elderCaves) return 'Древние пещеры';
    return id;
  }
}
```

### Шаг 2. Зарегистрируйте объект `Dungeon`
В `lib/data/dungeons.dart`:
```dart
const Dungeon elderCavesDungeon = Dungeon(
  id: 'elderCaves',
  name: 'Древние пещеры',
  description: 'Древние пещеры, населённые гоблинами и орками.',
  levelsCount: 3,
  icon: Icons.landscape_rounded,
  accentColor: Color.fromARGB(255, 193, 126, 20),
  isAvailable: true, // true = подземелье открыто для входа
);

const List<Dungeon> allDungeons = [
  cursedForestDungeon,
  catacombsDungeon,
  elderCavesDungeon,
];
```

### Шаг 3. Добавьте локализацию
В `lib/app_localizations.dart` укажите перевод названия и описания:
```dart
String dungeonName(String id, String fallback) {
  if (!_isRu) {
    if (id == 'cursed_forest') return 'Cursed Forest';
    if (id == 'catacombs') return 'Forgotten Catacombs';
    if (id == 'elderCaves') return 'Ancient Caves';
  }
  return fallback;
}
```

### Шаг 4. Наполните подземелье событиями и боссами
В `lib/data/events.dart`:
1. Создайте карты с `dungeonId: DungeonId.elderCaves` для уровней 1, 2, 3.
2. Создайте трёхфазных боссов в `allBossCards` (для каждого уровня 1, 2, 3 рекомендуется создавать пул из 2–3 вариантов боссов, чтобы на каждом этаже встречался случайный босс соответствующего уровня).

## 8. Ежедневные награды и система заданий

### 8.1. Мировое время и защита от эксплойтов (`WorldTimeService`)
- Расположение: `lib/services/world_time_service.dart`.
- **Механика**:
  - Получает истинное мировое время по протоколу HTTP (заголовки `Date` высоконадежных серверов Google, Cloudflare или Time API).
  - Во время работы приложения отсчёт времени ведётся по монотонному аппаратному счётчику `Stopwatch` (тики CPU), который полностью защищён от любых изменений системного времени пользователем в настройках телефона.
  - **Защита от отката назад (Rollback)**: сохраняет в `SharedPreferences` максимальную зафиксированную отметку времени (`world_time_last_known_ms`). При попытке перевести системные часы назад блокирует получение наград до восстановления времени.
  - **Защита от перемотки вперёд**: для перехода на следующий день и выдачи наград/заданий нового дня требуется подтверждённая синхронизация с мировым временем, что исключает возможность многократного получения наград в оффлайне.

### 8.2. Ежедневные награды за вход (`DailyRewardService`)
- Расположение: `lib/services/daily_reward_service.dart`.
- **Правила**:
  - 7-дневный цикл наград: день 1 = 100 монет, каждый следующий день +100 монет (день 7 = 700 монет).
  - **Ценные ключи за стрик**:
    - **День 3**: +1 серебряный ключ 🗝️;
    - **День 5**: +3 серебряных ключа 🗝️;
    - **День 7**: +1 золотой ключ 🔑 (джекпот недели).
  - После 7-го дня стрик циклически сбрасывается на 1-й день.
  - Если пропущен хотя бы один календарный день, серия сбрасывается на 1-й день.
  - Расчёт дня привязан к полночи по **Московскому времени** (UTC+3, MSK) на базе мирового времени:
    ```dart
    static DateTime get nowMsk => WorldTimeService.instance.nowMsk;
    ```
  - При первом входе за день в `MenuScreen` автоматически всплывает модальный диалог `DailyRewardDialog`.

### 8.3. Ежедневные задания (`DailyQuestsService`)
- Расположение: `lib/services/daily_quests_service.dart`.
- Экран: `lib/screens/quests_screen.dart` (кнопка в главном меню между «Инвентарь» и «Глоссарий»).
- Каждые сутки в полночь по МСК генерируются **2 случайных уникальных задания** из 5 типов:
  1. `DailyQuestType.dungeonRuns` — сыграть 1–3 подземелий (до победы или поражения);
  2. `DailyQuestType.killBosses` — убить 3–5 боссов;
  3. `DailyQuestType.clearDungeon` — успешно пройти 1 подземелье;
  4. `DailyQuestType.encounterCards` — встретить 30 карт определённого типа (`monster`, `trap`, `treasure` и т.д.);
  5. `DailyQuestType.specificDungeonRuns` — сыграть 1–3 раза в конкретное доступное подземелье (например, «Проклятый лес» или «Заброшенные катакомбы»).
- Награда за выполнение каждого ежедневного квеста: **150 монет**.
- **Бонус за выполнение всех ежедневных заданий дня**: **2 серебряных ключа 🗝️** (`DailyQuestsService.allDailyQuestsSilverKeysReward = 2`). Забирается на экране заданий, статус сбрасывается в 00:00 (МСК) вместе с генерацией новых заданий.

### 8.4. Еженедельные задания
- Управляются также через `DailyQuestsService` (`weeklyQuests`).
- Сброс происходит каждый **понедельник в 00:00 по Московскому времени (UTC+3, MSK)** на базе мирового времени `WorldTimeService.instance.thisWeekMskKey`.
- Каждую неделю генерируются **2 уникальных еженедельных задания**, повторяющих типы ежедневных, но усложнённых в **3–5 раз**:
  1. `dungeonRuns` — 5–10 забегов;
  2. `killBosses` — 12–20 боссов;
  3. `clearDungeon` — 3–5 успешных прохождений подземелий;
  4. `encounterCards` — 90–150 карт определённого типа;
  5. `specificDungeonRuns` — 5–10 забегов в конкретном подземелье.
- Награда за выполнение каждого еженедельного квеста: **500 монет**.
- **Супер-бонус за выполнение всех еженедельных заданий недели**: **2 золотых ключа 🔑** (`DailyQuestsService.allWeeklyQuestsGoldKeysReward = 2`). Забирается на экране заданий, статус сбрасывается каждый понедельник в 00:00 (МСК).
- Прогресс ежедневных и еженедельных заданий начисляется одновременно во время игровых событий (`onDungeonFinished`, `onBossKilled`, `onCardEncountered`).

## 9. Валюты игры

Управление валютами сосредоточено в `lib/services/player_coins_service.dart`:

- **Золотые монеты** (`coins`): основная валюта забега и магазина для покупки предметов и прокачки.
- **Серебряные ключи** (`silverKeys`): редкая валюта для открытия сундуков и контента.
- **Золотые ключи** (`goldKeys`): премиальная валюта.

Виджет отображения валют: `lib/widgets/currencies_bar.dart` (используется в главном меню, магазине, инвентаре и экране заданий).

### Настройка сундуков в магазине (`ShopScreen` и `ShopChest`):
Сундуки конфигурируются через модель [ShopChest](lib/models/shop_chest.dart) и объявляются в [defaultShopChests](lib/data/shop_chests.dart):
1. **Сундук новичка** (`novice_chest`): содержит 6 базовых карт 1 уровня (`levels: [1]`, базовая цена: 50 🪙, шаг: +25 🪙): `medicinal_herbs` (+2 HP), `whetstone` (+2 ⚡), `runic_shield` (50% защиты), `potion_antidote` (снятие дебаффов), `scroll_skip` (пропуск), `handful_of_gold` (горсть золота, +50 🪙);
2. **Сундук приключенца** (`adventurer_chest`): содержит 11 продвинутых карт 2 уровня (`levels: [2]`, базовая цена: 75 🪙, шаг: +35 🪙): апгрейды характеристик (`potion_heal` +4 HP, `potion_attack` +4 ⚡, `potion_regeneration` +6 HP), защиты (`divine_runic_shield` 100% блок, `potion_stoneskin` иммунитет 3 хода, `thornmail`), улучшенного побега (`smoke_bomb`, `gold_bribe`), фарма (`greed_magnet`, `dice_of_fate`) и `small_gold_pouch` (маленький мешочек золота, +100 🪙);
3. **Сундук героя** (`hero_chest`): содержит 6 легендарных артефактов 3 уровня (`levels: [3]`, базовая цена: 100 🪙, шаг: +50 🪙): `enhanced_runic_shield` (50% на 3 хода), `mirror_distortion` (инверсия потерь в прибыль), `scroll_teleport` (пропуск 1–3 карт), `philosophers_stone` (золото в статы), `shadow_pact` (риск/награда), `bag_of_gold` (мешок золота, +250 🪙);
4. **Серебряный сундук** (`silver_chest`): открывается за серебряные ключи и содержит эликсиры, пространственную червоточину и богатство (`itemIds: ['elixir_life', 'elixir_attack', 'huge_bag_of_gold', 'wormhole']`, `currency: ChestCurrency.silverKeys`, цена: 1 🗝️, шаг: +2 🗝️ [1, 3, 5, 7 🗝️; `wormhole` перемещает вперёд на 2–4 карты]);
5. **Золотой сундук** (`gold_chest`): открывается за золотые ключи и содержит божественные реликвии, чёрную дыру и казну (`itemIds: ['divine_healing', 'divine_power', 'enhanced_divine_runic_shield', 'chest_of_gold', 'black_hole']`, `currency: ChestCurrency.goldKeys`, цена: 1 🗝️, шаг: +2 🗝️ [1, 3, 5, 7, 9 🗝️; `black_hole` перемещает вперёд на 5 карт]).

#### Валюты и гибкая настройка сундуков:
Класс `ShopChest` поддерживает любые комбинации карт и валют:
- **Валюта открытия**: `currency: ChestCurrency.coins` (монеты, по умолчанию), `ChestCurrency.silverKeys` (серебряные ключи) или `ChestCurrency.goldKeys` (золотые ключи);
- **По уровням**: `levels: [1, 2, 3]` — сундук со всеми уровнями;
- **По конкретным ID**: `itemIds: ['potion_heal', 'thornmail', 'philosophers_stone']`;
- **Исключение карт**: `excludeItemIds: [...]` — исключение определенных ID из пула;
- **Комбинированный**: `levels: [1], itemIds: ['philosophers_stone']` — карты 1 уровня плюс конкретная редкая реликвия;
- **По предикату**: `filter: (item) => item.effectType == ItemEffectType.attack` — например, сундук воина;
- **Явные карты**: `explicitItems: [customCard1, customCard2]`.
