# Card Dungeon

A new Flutter game.

## Changelog:

**0.0.9**
- Работа с интерфейсом для маленьких экранов
- Добавлен новый прокачиваемый навык, отвечающий за получение карт на старте игры
- Переработка хроник, теперь содержат всю информацию о забеге
- Фиксы карт предметов

**0.0.8**
- Возможность сворачивать/разворачивать категории карточек событий/предметов
- Добавлен экран хроника, записывающий хронику пяти последних забегов
- Фиксы размеров интерфейса
- Добавлен новый прокачиваемый навык, отвечаемый за гарант появляение торговцев за уровень подземелья

**0.0.7**
- Окно победы в конце данжа
- Улучшения характеристик персонажа в инвентаре
- Исправление ошибок и багов

**0.0.6**
- История событий на экране окончания игры

**0.0.5**
- Уровни подземелья
- Боссы
- Обновлённый глоссарий с отображением типов карточек

**0.0.4**
- Дебаг-меню для тестирования игры
- Открытие всех событий и предметов через дебаг-меню

**0.0.3**
- Активные карточки в лутбоксах с уникальными навыками
- Расширенный набор действий (атака, щит, яд, лечение и др.)

**0.0.2**
- Бесконечное подземелье
- Карточки действий (активные предметы), применяемые один раз за ход
- Лутбоксы с предметами в качестве наград
- Инвентарь с предметами и монетами игрока
- Монеты используются во время игры
- Блокирование действия, если не хватает атаки или золота

**0.0.1**

- Базовая механика игры
- Глоссарий с карточками
